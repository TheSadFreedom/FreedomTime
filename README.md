# FreedomTime

FreedomTime следит за перерывами в Windows. По таймеру она либо блокирует экран, либо показывает напоминание.

По умолчанию 45 минут работы и 7 минут перерыва. За 5 минут до перерыва появляется предупреждение, его можно отложить на 20 минут.

## Запуск

Скачайте `FreedomTime.exe` со [страницы релизов](https://github.com/TheSadFreedom/FreedomTime/releases/latest) и откройте его. Установщик и Python не нужны, права администратора тоже.

Программа только для Windows. Повторный запуск не открывает вторую копию.

Закрытие и сворачивание окна прячут FreedomTime в трей (стрелка ^ на панели задач). Чтобы выйти, выберите «Выход» в меню иконки или нажмите Ctrl+Alt+Q.

При первом запуске программа добавляется в автозагрузку Windows. Это можно выключить в настройках.

## Окно

На главном экране кольцо показывает, сколько осталось до перерыва или до конца перерыва.

- **Перерыв сейчас** начинает перерыв, не дожидаясь таймера.
- **Отложить** доступна только в последние 5 минут работы и сдвигает перерыв на 20 минут.
- **Настройки** открываются в этом же окне.

Кнопка булавки в заголовке держит окно поверх остальных.

## Настройки

- **Запускать вместе с Windows** включает и выключает автозагрузку.
- **Время работы** и **время перерыва** задаются в минутах. Рядом с числом есть кнопки − и +. Новое время применяется к текущему отсчёту.
- **Блокировка экрана** на время перерыва выключает мышь, звук и микрофон и показывает таймер на весь экран.
- **Напоминание** показывает окно с таймером. Его можно закрыть и продолжить работать: перерыв всё равно идёт, пока время не кончится или вы не нажмёте «Закончить перерыв».

Нажмите **Сохранить**, чтобы запомнить настройки. Они сохраняются и после перезапуска.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+U | Закончить перерыв |
| Ctrl+Alt+Q | Выйти из программы |
| Escape, удерживать 3 секунды | Пропустить перерыв в режиме блокировки |

В режиме напоминания Escape перерыв не пропускает: закройте окно или нажмите «Закончить перерыв».

## Запуск из исходников

Нужен Python 3 для Windows.

```powershell
pip install -r requirements.txt
python freedom_time.py
```

`python freedom_time.py --test` запускает короткий цикл, чтобы проверить предупреждение и перерыв.
